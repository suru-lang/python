# 今後の候補

「Python」(suru-lang/python)で、まだ作っていないことです。

- **Python から する の関数を呼び返す。** する の関数を Python の呼べる物にして渡す(コールバック、sort の key など)。本体の「C から呼び戻す」(`呼び戻し番地作成する`)の入口を、包みの中の Python の型から呼ぶ形が考えられます。引数の数や型に制限があります。
- **数のリストを速く受け渡す。** 今は `JSON` を通すか、`Python一覧にする` で1つずつ受け取ります。数・小数のリストを、`バイト列` に詰めて一度に渡す関数があると、numpy の配列などで速くなります。
- **手札を GC と結ぶ。** 本体に後始末の仕組み(GC で値が消えるときに呼ぶ関数)ができたら、`Python物` を自動で放せます。
- **Python を止める。** `Py_FinalizeEx` を呼ぶ `Python終了する`。拡張モジュールの中には止めた後に始め直せないものがあるので、作るなら一度きりにします。
- **サブインタープリターや GIL なしの Python(3.13 の free-threaded)。** 並列に動かすため。
- **例外の型で分ける。** 今の失敗は文だけです。`成否` で、例外の型の名前と文を分けて返す関数があると、型ごとに扱いを変えられます。
- **Windows の python.org の Python と venv の確かめ。** CI は MSYS2 の Python だけを試しています。
